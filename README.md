## Playwright ба Selenium харьцуулалт
Playwright ашиглахад элемент бэлэн болохыг автоматаар хүлээдэг (auto-wait) шинж чанар нь нэмэлт хүлээлт бага бичиж, тестүүдийг илүү тогтвортой ажиллуулахад тусалж байгаа нь анзаарагдлаа. Локатор бичих арга барилын хувьд `getByTestId` зэрэг сонголт нь хуудасны дотоод бүтэц бага зэрэг өөрчлөгдөхөд эвдрэх эрсдэлийг бууруулж байна. Мөн `--trace on` ашиглахад алхам бүрийн төлөв, сүлжээний хүсэлт болон дэлгэцийн зургийг нэг дороос харах боломжтой байсан нь алдаа олоход их амар байлаа. Нөгөө талаар Selenium нь олон програмчлалын хэл болон хуучин системүүдтэй өргөн нийцдэг учраас томоохон уламжлалт орчинд өөрийн байр суурьтай хэвээр санагдсан. Гэхдээ шинээр суралцагчийн хувьд Playwright-ийн суулгалт, тохиргоо болон тайлан харах урсгал илүү цэгцтэй, ойлгомжтой байв. Тест бичих явцад хаалттай цэс эсвэл динамик төлөвийг зөв тооцоолоогүй тохиолдолд timeout гарах нь хэрэгслээс үл хамааран анхаарах ёстой зүйл гэдгийг ойлгосон. Дүгнэж хэлэхэд энэ дасгалын хүрээнд Playwright нь хурд, хяналт болон дебаг хийх боломжоороо илүү таатай сэтгэгдэл төрүүллээ.
