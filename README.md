# Playwright эхний тест

Энэ төсөл SauceDemo сайтад Playwright болон TypeScript ашиглан гурван тусдаа UI тест ажиллуулна. Тестүүд амжилттай нэвтрэх, буруу нууц үгийн алдаа, барааг сагсанд нэмэх үйлдлийг шалгадаг. Тест бүр тусдаа browser context ашигладаг бөгөөд амжилттай нэвтэрсэн урсгалууд logout хийж дуусна. Шаардлагатай орчин нь Node.js 18 ба түүнээс дээш хувилбар юм. `npm install` болон `npx playwright install` тушаалаар хамаарал, браузеруудаа суулгана. `npx playwright test` тестүүдийг ажиллуулж, `npx playwright show-report` HTML тайланг нээнэ. `npx playwright codegen https://www.saucedemo.com` тушаалаар код үүсгэн харьцуулж, `npx playwright test --trace on` ажиллуулсны дараа `npx playwright show-trace test-results/<test-folder>/trace.zip` тушаалаар мөрийг нээнэ; бичлэг үүсгэхдээ `npx playwright test --video on` ашиглана. Playwright нь Chromium, Firefox, WebKit дээр нэг API-аар ажиллаж, хурдан auto-wait болон trace хэрэгслүүд санал болгодог. Selenium нь олон хэл, браузер, WebDriver экосистемээрээ өргөн нийцтэй бөгөөд байгууллагын хуучин системүүдэд түгээмэл. Энэ дасгалд Playwright-ийн locator, assertion, мөрийн хэрэгслүүд UI тест бичихэд цэгцтэй байгааг ажиглав.
